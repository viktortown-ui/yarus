# Скачать ЯРУС 2.0.0

## Для компьютера Windows

Скачайте архив, полностью распакуйте его в обычную папку и запустите
`YARUS.exe`:

**https://github.com/viktortown-ui/yarus/releases/download/v2.0.0/YARUS-2.0.0-Windows-x64.zip**

Не запускайте программу прямо из ZIP: рядом с `YARUS.exe` находятся файлы,
которые нужны приложению для работы.

## Для телефона и планшета Android

APK для ручной установки:

**https://github.com/viktortown-ui/yarus/releases/download/v2.0.0/YARUS-2.0.0-Android.apk**

Одна сборка адаптируется под телефон, планшет и ориентацию экрана.

## Автономная браузерная версия

Сохраните HTML-файл и открывайте его в одном профиле браузера по постоянному пути:

**https://github.com/viktortown-ui/yarus/releases/download/v2.0.0/YARUS-2.0.0-Web.html**

Данные хранятся в профиле браузера, не внутри HTML. Перед очисткой браузера или
сменой пути сохраните внешнюю копию. Личный режим не требует подключения к сети.

## Страница выпуска

Описание версии, инструкция и контрольные суммы:

**https://github.com/viktortown-ui/yarus/releases/tag/v2.0.0**

## Зеркало на Яндекс Диске

Один архив с Windows, Android, автономным HTML, инструкцией и контрольными суммами:

**https://disk.yandex.ru/d/7bR5JwGfIvDKpg**

## Перед обновлением

Сохраните полную внешнюю копию. В общей базе сначала обновите главное устройство,
затем клиенты. После новых пакетных записей 2.0 рабочий журнал нельзя открывать
старым сервером 1.x. Исходную папку 1.3.2 сохраните для возврата к старой копии.

## Безопасность

Скачивайте ЯРУС только по ссылкам из этого файла или из настроек приложения.
Программа не загружает вашу базу на GitHub, Яндекс Диск или RuStore автоматически.
