# Скачать ЯРУС

## GitHub

Актуальный официальный выпуск:

**https://github.com/viktortown-ui/yarus/releases/latest**

На странице выпуска доступны:

- архив Windows x64 — распакуйте его полностью и откройте `YARUS.exe`;
- APK Android — один файл для телефона и планшета;
- файл `SHA256SUMS.txt` для проверки загрузки.

## Яндекс Диск

Официальное зеркало:

**https://disk.yandex.ru/d/JJikcv1kqzcWaw**

В архиве `YARUS-1.2.0-для-Яндекс-Диска.zip` находятся версии для Windows и
Android, инструкция и контрольные суммы. На Android рекомендуется устанавливать
и обновлять приложение через RuStore.

## Безопасность

Скачивайте ЯРУС только по ссылкам из этого файла или из настроек приложения.
Программа не загружает вашу базу на GitHub или Яндекс Диск автоматически.
