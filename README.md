# ЯРУС 1.1.2 — автономный склад для Windows и Android

ЯРУС ведёт товары, места, остатки и неизменяемую историю движений. Данные склада
остаются у владельца: облачный аккаунт разработчика не нужен. Один общий склад
имеет ровно одно главное устройство, поэтому движения не размножаются при
синхронизации.

## Что готово

- Windows x64: переносимая папка с понятным `YARUS.exe`; рабочие файлы создаются
  в подпапке `data`.
- Android 7.0+: один адаптивный APK для телефона и планшета и подписанный AAB
  для RuStore. Package id: `ru.viktortown.yarus`.
- Главным может быть Windows-компьютер, Android-телефон или планшет. Компьютер
  рекомендуется для постоянной команды; мобильный главный склад доступен коллегам
  только пока ЯРУС открыт и устройство находится в сети.
- Роли: владелец, администратор, менеджер, кладовщик и просмотр. Владелец один;
  его нельзя понизить или заменить через обычное управление участниками.
- Одноразовые приглашения по QR или адресу, очередь при временной потере связи,
  защита каждой команды от повторного проведения.
- Безопасный перенос главного устройства через зашифрованный `.yarus`-файл и
  отдельный 20-символьный код. Старое главное устройство сразу становится копией
  только для чтения; независимые склады автоматически не объединяются.
- Шифрование главной базы: Windows — AES-256-GCM, ключ защищён Windows DPAPI;
  Android — AES-256-GCM, неэкспортируемый ключ в Android Keystore. Журнал и
  внутренние копии заменяются атомарно.
- Приход, расход, перемещение, пересчёт и контролируемая отмена; защита от дублей
  артикула и штрихкода, включая архив.
- QR товаров, мест и приглашений; EAN-13, EAN-8 и базовый Code 128; камера,
  изображение или внешний сканер-клавиатура.
- Этикетки PDF/SVG, отчёт остатков PDF, CSV каталога/истории, полная JSON-копия,
  настраиваемые виджеты, Android-виджет, светлая/тёмная тема.
- Личный склад можно привязать к универсальному файлу `.yarus.json`: на Android
  файл хранится вне приложения и автоматически обновляется после каждого
  изменения. После удаления/переустановки ЯРУС пользователь выбирает этот файл
  снова; товары, места и история восстанавливаются без паролей и токенов.
- Встроенная понятная инструкция, отключаемые подсказки и поддержка:
  `fixerkrk@yandex.ru`, Telegram `@bertosh1`.
- В настройках Windows есть официальный раздел загрузки: актуальный GitHub
  Release и стабильная страница зеркала Яндекс Диска. Android направляет за
  обновлением только в RuStore. Складские данные при переходе не передаются.
- Официальный RuStore In-app Review SDK 10.5.1. Форма оценки запрашивается только
  после осмысленного использования: не менее 7 движений в 3 разные даты и не чаще
  одного внутреннего запроса за 120 дней.

## Быстрая проверка

Актуальные установщики и состояние зеркал: [DOWNLOADS.md](DOWNLOADS.md).

### На компьютере

1. В готовом комплекте откройте `ЗАПУСТИТЬ ЯРУС 1.1.2.exe`. Если рядом лежит
   прежний комплект 1.1.1, сначала полностью закройте старый ЯРУС: запускалка
   безопасно скопирует его зашифрованную базу и сохранённый вход, а старую папку
   оставит резервной копией.
2. При отдельной установке полностью распакуйте `YARUS-1.1.2-Windows-x64.zip`,
   например в `D:\YARUS`, и откройте `YARUS.exe`. Не запускайте его прямо из ZIP
   или `Program Files`.
3. Для нового склада выберите личный либо создайте общий. Для команды оставляйте
   ЯРУС открытым.

### На телефоне или планшете

1. Установите `YARUS-1.1.2-RuStore.apk` и откройте его.
2. Для работы с компьютерным складом на компьютере откройте
   «Настройки → Участники и приглашения», оставьте первый рекомендуемый адрес и
   создайте приглашение. На Android нажмите «Сканировать QR камерой» — адрес и
   код заполнятся сами. Оба устройства должны быть в одной доверенной Wi-Fi/LAN сети.
3. Если компьютера нет, на Android выберите «Сделать это устройство главным».
   Коллеги смогут работать только пока ЯРУС открыт на этом телефоне/планшете.
4. Для личного склада откройте «Настройки → Сохранность данных → Создать и
   подключить файл». Выберите, например, папку `Документы`. Файл `.yarus.json`
   останется после удаления приложения; после переустановки нажмите «Открыть файл
   личного склада» и выберите его.

## Как не получить двойной склад

- На всех устройствах команды подключайтесь к одному главному устройству.
- Не создавайте новый личный склад вместо входа по приглашению.
- При смене главного используйте только «Передать главный склад». Полученный
  `.yarus`-файл откройте на пустом новом главном устройстве и введите код отдельно.
- Если два человека независимо меняли две разные базы, автоматического слияния нет:
  это сознательная защита от двойных приходов и расходов.

## Копии и восстановление

- JSON-копия содержит каталог и полную историю, но не пароли и не сессии.
- `.yarus.json` — та же переносимая версия личного склада. На Android подключённый
  файл обновляется автоматически; на Windows его сохраняют и открывают вручную.
  Файл не зашифрован, поэтому храните его только в доверенной папке.
- `.yarus` переносит всё главное состояние, включая участников, поэтому всегда
  зашифрован. Потерянный код восстановления невозможно подобрать средствами ЯРУС.
- На Windows файлы `data/yarus.journal` и `data/yarus.key` являются парой. Не
  переносите один без другого. Проще пользоваться встроенным переносом.
- Храните внешнюю копию отдельно от рабочего устройства.

## Честные границы

ЯРУС — оперативный учёт, не бухгалтерия и не ERP. Справочная оценка — не FIFO и
не средняя себестоимость. Нет обязательной маркировки, Data Matrix/GS1, партий,
серий, резервов и заказов поставщику. Базовый Code 128 не декодирует GS1/FNC.
Лимиты: 5000 товаров, 200 мест, CSV-импорт до 500 строк.

HTTP разрешён только внутри доверенной локальной сети. Порт 8787 нельзя напрямую
выставлять в интернет; для удалённой работы нужен отдельно настроенный HTTPS/VPN.
Android не может надёжно быть круглосуточным сервером в фоне: мобильный главный
склад работает только при открытом ЯРУС. Windows EXE не имеет платной
Authenticode-подписи, поэтому SmartScreen может показать «Неизвестный издатель».

Сборок для macOS, iPhone и iPad пока нет.
