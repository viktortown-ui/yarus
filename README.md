# ЯРУС 1.0.0 — автономный склад для Windows и Android

ЯРУС ведёт товары, места хранения, остатки и неизменяемую историю движений.
Приложение работает без облака и без аккаунта разработчика. Личный склад хранится
только на устройстве. Для одного общего склада компьютер с ЯРУС становится локальным
сервером, а телефоны и планшеты подключаются к нему по одноразовому QR‑приглашению.

## Что готово

- Windows x64: переносимая папка с `YARUS.exe`; данные и WebView‑профиль создаются
  внутри подпапки `data`. Установщик не требуется.
- Android 7.0+: один адаптивный APK для телефона и планшета, плюс подписанный AAB
  для RuStore. Package id: `ru.viktortown.yarus`.
- Общий склад: владелец, сотрудник и просмотр; одноразовые приглашения; очередь
  при потере связи; серверная идемпотентность защищает движение от повтора.
- Защита каталога от дублей артикула и штрихкода, включая архивные карточки.
- Приход, расход, перемещение, пересчёт и контролируемая отмена владельцем.
- QR товаров, мест и приглашений; EAN‑13, EAN‑8 и базовый Code 128; камера,
  изображение или внешний USB/Bluetooth‑сканер как клавиатура.
- QR‑этикетки: одна 70×40 мм или до 12 одинаковых на A4, экспорт в PDF/SVG.
- Отчёт остатков в PDF: сводный или по местам; CSV остатков/истории; полный JSON backup.
- Настраиваемые виджеты обзора, Android‑виджет последнего состояния склада,
  светлая/тёмная тема, компьютерная, планшетная и мобильная раскладка.
- Серверный журнал с `fsync`, блокировкой второго процесса и ротацией 30 резервных копий.

## Как пользоваться готовой сборкой

1. Полностью распакуйте `YARUS-1.0.0-Windows-x64.zip` в обычную папку, например
   `D:\YARUS`. Не запускайте программу прямо из ZIP или из `Program Files`.
2. Откройте `YARUS.exe`. На первом экране создайте общий склад либо выберите личный.
3. Для синхронизации: на компьютере откройте «Настройки → Участники и приглашения»,
   создайте QR; на Android выберите «Считать QR‑приглашение».
4. Компьютер и Android должны видеть друг друга в одной доверенной Wi‑Fi/LAN сети.
   Синхронизация работает, пока компьютер с ЯРУС включён.
5. Регулярно используйте «Настройки → Выгрузить полную копию» и храните файл отдельно.

Подробная инструкция входит в Windows‑архив как `ИНСТРУКЦИЯ.html`.

## Важное об обновлении старой beta

Ключ экспериментального APK 0.10.0 не сохранился. Новый магазинный релиз подписан
постоянным ключом 1.0.0, поэтому Android может потребовать удалить beta. Сначала в
старой версии выгрузите полную JSON‑копию, затем удалите beta, установите 1.0.0 и
восстановите копию. CSV не заменяет полную копию с историей.

Windows 1.0.0 переносим: старые браузерные данные автоматически не объединяются.
Перенесите их полной JSON‑копией. Независимые локальные склады не сливаются молча:
это защищает историю от неоднозначных дублей. Для нескольких устройств сразу
создавайте именно общий склад на компьютере.

## Сборка

Windows:

```powershell
.\tools\build_windows.ps1
.\tools\package_windows.ps1
```

Android release использует Android Gradle Plugin 8.13.2, Gradle 8.13,
compile/target SDK 36, min SDK 24 и Java 17. Приватный ключ не входит в Git:

```powershell
.\tools\build_android_release.ps1
```

Общий автономный HTML для обеих оболочек собирает `python tools/pack_web.py`.
Сценарий `tools/legacy/build_android_offline.py` оставлен только как исторический инструмент
beta и не используется для релиза 1.0.0.

## Проверки

```powershell
go test ./...
node --test tests/domain.test.cjs tests/codes.test.cjs tests/reports.test.cjs tests/upgrade.test.cjs
node tests/ui_release.cjs
```

Дополнительно релиз проверяется через `apksigner`, `jarsigner`, реальный запуск
Windows‑окна, HTTP API, открытие PDF, контроль размеров RuStore‑скриншотов и установку
APK на Android 16. На эмуляторе проверены сохранение данных, системный виджет,
Android Photo Picker, распознавание EAN‑13, JSON‑копия и PDF‑экспорт.

## Честные границы

ЯРУС — оперативный складской учёт, не бухгалтерия и не ERP. Справочная оценка —
не FIFO и не средняя себестоимость. Нет обязательной маркировки, Data Matrix/GS1,
партий, серий, резервов, заказов поставщику и автоматического облачного сервера.
Базовый Code 128 не декодирует GS1/FNC. Лимиты: 5000 товаров, 200 мест, CSV‑импорт
до 500 строк. Порт 8787 нельзя открывать напрямую в интернет; для удалённой работы
нужен отдельно настроенный HTTPS. Живая Android‑камера и печать требуют физической
приёмки на ваших устройствах. Windows EXE не имеет платной Authenticode‑подписи,
поэтому SmartScreen может показать предупреждение «Неизвестный издатель».

Сборок для macOS, iPhone и iPad нет.
