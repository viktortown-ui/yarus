ЯРУС · 2.0.0 · локальный кандидат

Запасы и имущество под контролем.

Учёт на своём устройстве или совместная работа с одной общей базой.

Попробовать на компьютере

  1. Закройте прежний ЯРУС.
  2. Распакуйте весь комплект. Откройте ЗАПУСТИТЬ ЯРУС 2.0.0.exe.
  3. Для первого знакомства выберите учебный склад. Для чистой проверки без переноса старой базы запустите YARUS.exe из папки 01-Windows/YARUS-2.0.0-Windows-x64.
  4. На главном экране доступны основные действия. В каталоге откройте карточку позиции и посмотрите, где она хранится.
  5. В настройках оставьте нужные возможности. Их отключение скрывает дополнительные элементы интерфейса и не удаляет складские данные.

Обычная запускалка копирует соседнюю базу 1.3.2 в отдельную папку 2.0.0. После проверки пользуйтесь одной рабочей копией: независимо изменённые базы не объединяются.

Телефон и планшет

Установите подписанный APK из папки 02-Android поверх стабильного ЯРУС. Перед обновлением сделайте внешнюю копию. При обычном обновлении удалять приложение не требуется.

Интерфейс использует те же правила учёта, что и компьютер. Для личной работы выберите склад на устройстве. Для команды считайте QR-приглашение с главного устройства.

Одна общая база

  1. Создайте общий склад на компьютере либо назначьте Android главным.
  2. Откройте настройки участников, выберите роль и создайте приглашение.
  3. На другом устройстве считайте QR. Устройства должны видеть друг друга в одной доверенной сети.
  4. Проверьте одинаковое название склада и статус синхронизации. Сделайте тестовый приход и сверьте историю на втором устройстве.

Без связи клиент показывает сохранённые остатки и хранит новые операции в черновиках. Подтверждённое движение не повторяется при повторной отправке. Для постоянно работающей команды главным надёжнее назначить компьютер. Android доступен коллегам, пока ЯРУС открыт.

Копии и перенос

Сохраняйте полную JSON-копию отдельно от рабочего устройства. Личный Android-склад можно связать с файлом .yarus.json; после переустановки откройте этот файл на первом экране.

Для смены главного устройства используйте защищённый .yarus и отдельный код. Старое устройство окончательно передаёт роль после подтверждения нового.

Журнал общей базы 2.0.0 поддерживает новые атомарные документы. После первых записей его нельзя открывать сервером 1.x. Храните старую папку и внешнюю копию до обновления. Новые движения 2.0.0 не появятся в старой копии автоматически.

Складские данные не отправляются разработчику. Для доступа из интернета нужен HTTPS или VPN; не открывайте порт локального сервера напрямую.

Статус этого комплекта

Кандидат 2.0.0 не опубликован автоматически. Публичные ссылки стабильной версии 1.3.2 не заменены. Точный список проверок — в release-2.0.0-tests.txt.

ЯРУС ведёт оперативный учёт и не заменяет бухгалтерскую систему. Камеру конкретного телефона, печать этикеток и реальную сеть проверяйте на используемом оборудовании.
