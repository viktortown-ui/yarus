ЯРУС · 0.10.0 BETA

Обновить склад.
Добавить сканирование.

Телефон, Android-планшет и Windows-компьютер: одни карточки и правила, понятные коды, собственные этикетки.

Сначала полная копия. В старой версии откройте «Настройки → Выгрузить полную копию → Сохранить файл». Убедитесь, что JSON-файл действительно появился в выбранной папке. CSV не заменяет полную копию. Не удаляйте Android-приложение и не очищайте его данные.

1. Обновление телефона и Android-планшета

Откройте YARUS-0.10.0-Android.apk и подтвердите обновление существующего ЯРУС. Для телефона и планшета файл один. Подпись и идентификатор прежние. На первом запуске добавляется идентификатор склада для QR; остатки и история не пересчитываются.

После запуска проверьте «Настройки → О приложении»: 0.10.0 beta. Откройте старую «Канистру» и историю. После ваших тестов ожидаемый остаток — 0 шт: приход 20, расход 3 и расход 17. Не вводите эти операции повторно.

Если Android не предлагает обновление или сообщает о конфликте пакета, остановитесь: не удаляйте старый ЯРУС ради установки. Сохраните текст ошибки и резервную копию.

2. Обновление Windows

До закрытия старой версии выгрузите её полную JSON-копию. Затем закройте старый ЯРУС/сервер. Если использовали общий склад, скопируйте всю папку %LOCALAPPDATA%\Yarus\data в отдельное место. Новую ZIP-папку полностью распакуйте, затем откройте YARUS.exe.

Теперь это отдельное окно Win32 со встроенным WebView2, а не запуск вкладки сайта. Для него нужен установленный Microsoft Edge WebView2 Runtime x64. Он не включён в небольшой архив. При его отсутствии ЯРУС должен показать объяснение. Установщик Runtime берите только с официальной страницы Microsoft. EXE не подписан Authenticode: не отключайте защиту Windows ради запуска неизвестных файлов.

Важное различие: локальные данные старого Edge/браузера и нового WebView2 находятся в разных профилях. Они не перенесутся сами. Выберите личный склад в новой версии → «Настройки → Восстановить локальную копию» → старый JSON → подтверждение замены. Старый браузерный профиль не удаляется. Общий серверный журнал в прежней папке мигрирует отдельно, с резервной копией до изменения.

Основной EXE запускает и окно, и сервер. Закрытие окна останавливает этот сервер. Чтобы держать общий склад доступным отдельно, запустите ЗАПУСТИТЬ-СЕРВЕР.cmd и оставьте его окно открытым. Не запускайте одновременно второй сервер на том же порту. Для первичной настройки служебного сервера используйте созданный им файл OPEN-YARUS.url в папке данных; не передавайте его другим людям.

3. Считать заводской штрихкод

«Товары → Сканировать» → «Включить камеру». На телефоне разрешите доступ к камере для ЯРУС. Наведите на один QR или штрихкод целиком; держите ровно, без бликов. После считывания камера выключается. Если системный запрос прервал первый запуск, ещё раз нажмите «Включить камеру».

Известный код открывает карточку. Для неизвестного выберите «Привязать к существующему» и свою канистру либо «Создать товар». Повторный код другой карточки отклоняется. Старый внешний код при замене не остаётся вторым кодом — сейчас на карточку приходится один заводской код.

Камера и расшифровка работают локально. Фото не отправляется на сервер. Поддерживаются QR, EAN-13, EAN-8, обычный Code 128. Поштучная маркировка, Data Matrix, GS1/FNC/SHIFT не поддерживаются. Повреждённый или сильно наклонённый код может не прочитаться.

Без камеры: «Из изображения» либо поле ввода и Enter. Внешний USB/Bluetooth-сканер должен работать как клавиатура: установите курсор в поле кода, считайте код, затем Enter. Подключение конкретного сканера проверяется отдельно. В Windows используется веб-камера при её наличии.

4. Своя QR-этикетка товара

Откройте карточку → «QR-этикетка». Выберите одну наклейку 70×40 мм или лист A4, задайте от 1 до 12 одинаковых наклеек → «Сохранить PDF для печати». Откройте PDF и печатайте в масштабе 100% / «Фактический размер», без «Подогнать». На A4 два столбца и шесть рядов; это не шаблон любой покупной самоклейки. SVG сохраняет только сам QR.

Сначала проверьте одну напечатанную этикетку. QR содержит постоянный идентификатор, а не количество или цену. Изменение остатка не требует новой наклейки. Наклейка относится к конкретному складу; другой личный склад с похожим названием её не примет. QR не выдаёт права доступа.

5. QR полки или стеллажа

«Настройки → Места хранения» → у нужного места «QR-этикетка». Считанный QR фильтрует каталог по месту. В форме движения кнопки «Сканировать товар» и «Сканировать место» заполняют выбор, но не меняют введённое количество. Перемещение по-прежнему требует явного подтверждения.

6. Совместная работа

Обновите сервер и устройства до одной версии. На одном компьютере создайте общий склад, затем откройте «Настройки → Участники и приглашения». Выберите локальный IP-адрес компьютера, создайте приглашение и передайте адрес с кодом сотруднику лично. На другом устройстве: «Подключить общий склад → По приглашению».

Для первого теста используйте одну доверенную Wi-Fi/локальную сеть. Телефон может быть на Wi-Fi, компьютер — на кабеле того же роутера. Компьютер должен быть включён, сервер запущен; приватная сеть и разрешения приложения в брандмауэре не должны блокировать соединение. Не отключайте брандмауэр целиком. VPN может влиять на доступ к локальной сети — проверяйте его режим отдельно.

HTTP разрешён только в доверенной локальной сети. Не выставляйте 8787 напрямую в интернет. Для внешнего доступа нужен HTTPS на вашем сервере. Никакой VPS или публичное облако в этом обновлении не развёрнуты. В браузере по HTTP-адресу другого компьютера камера может быть недоступна: используйте установленный APK / Windows-приложение либо HTTPS.

Личный и общий склад — разные наборы данных. Автоматического объединения нет. Полная локальная копия не загружается в общий сервер одним нажатием. Без связи операции общего склада остаются черновиками до подтверждения, а не выдуманными актуальными остатками.

7. Приёмка после обновления

Проверьте старые товары и историю, выгрузку копии, затем один сканированный код и одну PDF-этикетку. Для движения используйте отдельный тестовый товар: приход 20 → расход 3 → остаток 17; расход 18 должен показать, сколько не хватает, и ничего не списать. Закройте и откройте приложение, проверьте сохранение. На втором участнике подтвердите появление тех же данных.

Граница проверки: код, сервер, моделируемый интерфейс, изображения кодов и PDF проверены автоматически. Установка нового APK, настоящая камера, нативное окно Windows, системные диалоги, реальная печать и устройство после обновления в этой среде не проверялись. Это beta, не гарантия отсутствия ошибок. До приёмки сохраняйте внешний backup и параллельный проверенный учёт.

Версия 0.10.0 · без внешнего CDN и LLM · исходники и протоколы проверок включены в комплект. Не бухгалтерия, не маркировка, не учёт партий/серий. macOS, iOS и iPadOS-сборок нет.
