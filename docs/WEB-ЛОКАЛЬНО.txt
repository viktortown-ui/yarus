ЯРУС — АВТОНОМНЫЙ ФАЙЛ ДЛЯ БРАУЗЕРА

Откройте YARUS.html в обычном браузере. Интерфейс и модули встроены в один файл;
для личного учёта сервер не нужен. Данные сохраняются в локальном хранилище
выбранного профиля браузера, а не внутри самого HTML-файла.

Используйте один профиль браузера и постоянный путь к файлу. Смена профиля,
очистка данных браузера или приватный режим могут сделать склад недоступным.
Перед переносом файла или обновлением сохраните полную внешнюю JSON-копию.

HTML использует тот же интерфейс и правила, что Windows и Android. Возможности
камеры, файлового выбора и локальных сетевых подключений зависят от браузера.
Для обычной ежедневной работы на Windows рекомендуется приложение из 01-Windows.
Нативной сборки для iPhone/iPad/macOS в этом комплекте нет.
