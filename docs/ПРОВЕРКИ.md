# Протокол проверки ЯРУС 1.1.2

Дата: 21 сентября 2026 года.

## Автоматические правила и безопасность данных

- `node --test`: 45/45 тестов прошли. Проверены дробные количества, отрицательные
  остатки, идемпотентность, конфликты, отмена, роли, 18 QR/штрихкод-образцов,
  PDF, зашифрованный перенос и совместимость резервных копий 0.9.1/0.10/1.x.
- Новый тест подтвердил: служебные поля универсального `.yarus.json` принимаются
  загрузчиком версии 1, но не попадают во внутреннее рабочее состояние.
- Отдельный тест запрещает выпуск, если в активном интерфейсе снова появится
  старая надпись версии вместо `1.1.2`.
- Проверены стабильные адреса загрузки: Windows показывает GitHub и страницу
  зеркала Яндекс Диска, Android — только официальную карточку RuStore.
- `go test ./...` прошёл для сервера, шифрованного журнала, DPAPI/AES, API,
  параллельных конфликтов, копий и запускалки Windows.
- Синтаксис `app.js`, `host.js`, `transfer.js` и нового UI-теста проверен Node.

## Интерфейс

- Playwright: телефон 360×640@3 и планшет 800×1280@2 без горизонтального выхода.
- Проверены учебный склад, каталог, история, места, настройки, EAN-13 из
  изображения, QR-этикетка и реальное создание PDF.
- Отдельные сценарии проверили Android как главное устройство и универсальный
  файл: создание, автоматическую запись после изменения и восстановление склада.
- Подготовлено 9 PNG 1080×1920 и 6 PNG 1600×2560, включая новые экраны файла
  склада. Размеры и внешний вид проверены.

## Универсальный файл личного склада Android

- На Android 16 emulator через настоящий системный выбор файлов создан
  `YARUS-Мой-склад.yarus.json` в `Downloads`.
- Начальный файл имел 564 байта. После создания товара автоматически вырос до
  891 байта и содержал 1 товар, `portable.appVersion=1.1.2`, без паролей.
- Debug-приложение полностью удалено. Файл остался в `Downloads`.
- После чистой повторной установки на первом экране выбран тот же файл. ЯРУС
  восстановил товар `TestCanister` и снова подключил автоматическое обновление.
- Тестовые debug-приложение и файл после проверки удалены с emulator.

## Windows

- Собраны `YARUS.exe`, `YARUS-server.exe` и запускалка x64; встроены иконки и
  манифест `asInvoker`.
- Тест запускалки подтвердил перенос 1.1.1 → 1.1.2: журнал, DPAPI-ключ и реальный
  профиль `YARUS.exe.WebView2` копируются в `data/desktop-webview` один раз;
  старые данные не изменяются, lock/URL не переносятся.
- Чистый упакованный `YARUS-server.exe` запущен на loopback. `/api/info` вернул
  `version=1.1.2`, `ready=false`; рабочая временная папка была изолирована.
- Реальная база и DPAPI-ключ перенесены в `D:\Yrus_sklad\YARUS-1.1.2-READY`,
  их SHA-256 совпали с источником. Сервер с перенесёнными данными вернул
  `version=1.1.2`, `ready=true`, `host.status=active`; созданы внутренние копии.
- SHA-256 для Windows-файлов создаётся упаковщиком. Windows EXE не имеет платной
  Authenticode-подписи, поэтому SmartScreen может предупредить пользователя.

- `lintDebug`, `assembleDebug`, release `clean assembleRelease bundleRelease` и

- APK проверен `apksigner`: подписи v2/v3, один RSA-4096 signer.

## Настоящее обновление Android 1.1.1 → 1.1.2

- На emulator стояла подписанная 1.1.1 (`2026092003`).
- `adb install -r` подписанного APK 1.1.2 завершился `Success`.
- После обновления: `2026092101`, `1.1.2`; `firstInstallTime` остался
  `2026-09-19 22:29:35`.
- Приложение открыло прежний учебный склад с 12 товарами и историей: данные не
  очищались.
- Точный финальный APK повторно установлен поверх той же версии: интерфейс
  показал `Версия 1.1.2`, 12 товаров сохранились. SHA-256 APK:
  `8960028d777fe5cca53a415bd9e7ba469feceba513b3ec5d3abb68487acd0eef`.

## Что требует физической приёмки владельцем

- камера и внешний файл проверены на Android emulator; на конкретном телефоне
  остаётся проверить разрешение камеры, выбранную папку и реальные этикетки;
- связь двух физических устройств в домашней/рабочей Wi-Fi сети и брандмауэр;
- окончательная карточка и анкета данных в актуальной RuStore Консоли;
- живой Review flow после публикации.

Статус внешней публикации не выводится из локальных тестов: его нужно проверять
на странице GitHub Release, в RuStore Консоли и по публичной ссылке Яндекс Диска.
