# Протокол проверки ЯРУС 1.3.1

Дата: 27 сентября 2026 года.

## Что проверено автоматически

- 52/52 Node-теста: остатки, дробные количества, роли, отмена движений,
  резервные копии, QR/штрихкоды, PDF, история по сегментам, большие цены,
  проверка EAN, безопасный перенос главного устройства и шифрованная локальная
  связь.
- Go-тесты сервера и запускалки Windows прошли полностью.
- Отдельный Java-тест подтвердил контрольную сумму EAN и требование трёх
  совпадающих кадров перед принятием штрихкода.
- Обычный HTTP-запрос с другого устройства отвергается; зашифрованный
  AES-256-GCM-запрос принимается. Пароль и токен отсутствуют в передаваемом
  тексте; повреждение и повтор пакета отвергаются.
- Два независимых главных устройства прошли весь перенос: подготовка,
  отмена, подтверждение на старом устройстве и активация нового.
- История перешла границу одного сегмента (5000 движений), восстановилась из
  полной копии и сохранила ограниченный кэш повторных команд.
- Большие цены и итоговая стоимость проверены целочисленной арифметикой.

## Интерфейс

- Playwright-проверки телефона, планшета и компьютера прошли без ошибок
  JavaScript и горизонтального выхода.
- Проверены быстрый главный экран, компактные переходы к категориям и истории,
  полноэкранный сканер, нативный Android-мост,
  подтверждение одномерного кода, полноэкранные категории и остатки, карточка товара,
  фильтры, меню переполнения, роли, перенос, универсальный файл и PDF.
- Проверены четыре размера окна: 360×780, 834×1112, 1112×834 и 1440×1000.
- Созданы 11 скриншотов телефона 1080×1920 и 6 планшета 1600×2560.
- PDF-этикетки отрисованы; QR считан обратно из растра готового PDF.

## Windows

- Собраны `YARUS.exe`, `YARUS-server.exe`, запускалка и ZIP x64.
- Финальный упакованный сервер запущен отдельно; `/api/info` вернул версию 1.3.1.
- Упакованный сервер выдержал работу двух пользователей, повтор команды после
  потерянного ответа и перезапуск без потери журнала или сессии.
- Запускалка проверена на переносе 1.3.0 → 1.3.1: копирует журнал, DPAPI-ключ и
  профиль WebView2 один раз, не переносит lock/URL и не меняет исходную папку.
- Windows EXE пока без платной Authenticode-подписи; SmartScreen может показать
  предупреждение «Неизвестный издатель».

## Android build и обновление

- Release-сборка APK/AAB и `lintVitalRelease` прошла: 59 задач Gradle.
- Пакет `ru.viktortown.yarus`: `versionName 1.3.1`,
  `versionCode 2026092702`, minSdk 24, targetSdk 36.
- APK проверен подписями v2/v3, AAB — JAR-подписью. Сертификат тот же постоянный
  RSA-4096; SHA-256 сертификата:
  `56fa7cf2f0dbfa1749100c9acbf24efa0896fa435a8433c46a73e5a9b4e12f8e`.
- На Android 16 emulator выполнено настоящее обновление подписанной версии
  1.3.0 → 1.3.1 через `adb install -r`. `firstInstallTime` сохранился,
  учебный склад с 12 товарами остался, в настройках показана версия 1.3.1.
- Верхняя панель проверена под системной строкой состояния, нижнее меню — над
  жестовой панелью: элементы не перекрыты.
- Нативный CameraX-сканер открылся на весь экран; локальный модуль ML Kit
  загрузился, нажатие по кадру успешно запустило фокусировку.
- Закрытие нативной камеры возвращает прямо в исходный экран. Диалог несохранённых
  данных подписан «ЯРУС», технического заголовка JavaScript больше нет.
- Разрешения финального APK сверены: INTERNET, CAMERA, ACCESS_NETWORK_STATE,
  RECEIVE_BOOT_COMPLETED и внутреннее signature-разрешение AndroidX.
