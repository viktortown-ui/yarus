# Архитектура 0.10.0

Один клиент web/* включён в Android APK, сервер и Windows локальное окно.
Это разделение оболочки и правил, а не три независимо развивающихся каталога.
Нативная оболочка использует системный WebView/Runtime, интерфейс локален.

## Идентичность

`space.id` — постоянная область имён. Формат QR: `YARUS:1:<space.id>:item|place:<id>`.
Роли и принадлежность сервера проверяются отдельно; QR не токен доступа.
Старый формат данных `yarus-data`, version=1 сохранён. Миграция только добавляет ID.
Идентификатор нельзя подменить переименованием склада. При клонировании полной
копии ID сохраняется, но клоны не становятся автоматически синхронизированными.

## Движения

Сканер → распознавание текста → проверка принадлежности → выбор товара/места.
Только подтверждение формы создаёт приход/расход/перемещение. Количество целое
в тысячных, не float. Двойная защита клиент/сервер, журнал до подтверждения fsync,
идемпотентный command.id, контроль версии карточки и пересчёта. Основная механика
0.9.1 сохранена. Нехватка показывается до отправки, конфликт сервера — отдельно.

## Защита и ограничения

Камера: только video, явное действие, остановка на pause/close; локальный декодер.
Содержимое QR не выполняется, ссылки не открываются, HTML экранируется.
Native bridge допускает только локальную страницу и пользовательские file dialogs.
Windows Runtime loader заимствует схему поиска из wailsapp/go-webview2 (ISC);
его реальная совместимость должна быть проверена на целевой Windows.
Автономная сборка Android не использует D8; полная ART-валидация ещё не выполнена.
Ключ Android не хранится в проекте/релизе. Windows Authenticode-подписи нет.

Интернет-сервер нужен только для доступа из разных сетей; в комплекте его нет.
HTTP — доверенная LAN, внешнее развёртывание через HTTPS reverse proxy.
Данные в файлах и IndexedDB не зашифрованы приложением. Резервная копия — чувствительный
документ. Обновление не добавляет аналитики/LLM/CDN.

## Границы следующего этапа

Физические устройства, камера/разрешения, WebView2 старт, file dialogs, настоящий
IndexedDB после обновления, принтеры и совместная работа на реальной LAN.
Затем стандартная SDK/D8 сборка, SDK target update и независимый security review.
Не добавлять партии, маркировку, автоматическое списание и слияние локальных
баз раньше завершения этих проверок.
