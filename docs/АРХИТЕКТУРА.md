# Архитектура ЯРУС 1.0.0

## Один интерфейс, три режима запуска

Канонический клиент находится в `web/`. `tools/pack_web.py` собирает его в один
автономный HTML для Android и Windows. Поэтому товары, QR, PDF, виджеты и правила
форм одинаковы на компьютере, телефоне и планшете.

- Android: нативная Java‑оболочка WebView, локальный asset, системные диалоги файлов.
- Windows: Go‑сервер и нативное Win32‑окно с официальным WebView2Loader.
- Headless: тот же Go‑сервер без окна для постоянной работы или HTTPS reverse proxy.

В переносимой Windows‑поставке маркер `YARUS-PORTABLE.flag` направляет серверный
журнал и профиль WebView2 в подпапку `data` рядом с EXE.

## Личный и общий склад

Личный режим хранит состояние в IndexedDB устройства. Общий режим использует
серверный append‑only журнал. Клиент хранит локальную подтверждённую копию и очередь
черновиков, но сервер остаётся источником истины. Независимые личные склады не
сливаются автоматически: без явного сопоставления это создало бы ложные дубли и
переписанную историю.

## Защита от повторов и конфликтов

Количество хранится целым числом тысячных, без ошибок float. У каждой команды есть
случайный `command.id`; сервер запоминает её содержимое. Повтор после потерянного
HTTP‑ответа возвращает уже полученный результат, а тот же id с другим содержимым
отклоняется. Артикул и внешний штрихкод уникальны во всём каталоге, включая архив.
Пересчёт проверяет версию остатка. Отрицательный остаток запрещён клиентом и сервером.

Журнал дописывается и синхронизируется на диск до успешного ответа. Второй процесс
блокируется файловым lock. Резервная копия сначала записывается во временный файл,
проверяется по размеру и атомарно переименовывается; только после успеха удаляются
старые копии сверх 30.

## QR и штрихкоды

Постоянный QR товара/места имеет область имён `space.id` и не является ключом доступа.
QR приглашения содержит адрес сервера, одноразовый код и срок действия, но пароль
пользователь задаёт сам. Поддержаны QR, EAN‑8, EAN‑13 и базовый Code 128. GS1/FNC,
Data Matrix и обязательная маркировка не заявлены.

## Граница безопасности

Android‑bridge доступен только встроенному origin; внешняя навигация блокируется.
Камера разрешается только этому origin и только для video. Windows‑bridge принимает
лишь локальный origin и ограниченный `saveText`. Имена/размеры экспортов проверяются.
HTTP допустим только для literal private IP/localhost; похожие домены отклоняются.
Для выхода за LAN требуется HTTPS reverse proxy. Данные на диске приложением не
шифруются, поэтому копии и папка `data` считаются чувствительными.

## Версии и сборки

Android: package `ru.viktortown.yarus`, versionCode `2026092001`, target SDK 36,
min SDK 24, AGP 8.13.2, Gradle 8.13, Java 17. APK/AAB подписываются постоянным
RSA‑4096 ключом вне Git. Windows x64 собирается Go 1.27.1 без сторонних Go‑модулей.
Windows Authenticode‑подписи пока нет.
