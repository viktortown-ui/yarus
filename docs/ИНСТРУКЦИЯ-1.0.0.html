ЯРУС · версия 1.0.0

Один склад
на ваших устройствах.

Windows‑компьютер хранит общий журнал локально. Телефон и планшет подключаются по QR. Никакого облака разработчика и обязательной регистрации.

1. Запуск на Windows

Полностью распакуйте ZIP.
Перенесите папку, например, в D:\YARUS. Не запускайте EXE прямо из архива и не помещайте папку в Program Files.
Дважды нажмите YARUS.exe. Если SmartScreen покажет «Неизвестный издатель», выберите «Подробнее → Выполнить в любом случае». EXE проверен контрольной суммой, но коммерческого сертификата Authenticode у проекта пока нет.
Если Windows спросит про брандмауэр, разрешите доступ только для частных сетей. Публичные сети отмечать не нужно.
На первом экране выберите «Создать общий склад», задайте название, логин и длинный пароль владельца. Сохраните пароль в менеджере паролей: разработчик не может его восстановить.
Где данные: внутри папки программы автоматически создаётся data. В ней находятся журнал, локальный профиль интерфейса, резервные копии и ссылка запуска. Не удаляйте эту папку и копируйте её только при закрытом ЯРУС.

2. Установка на телефон или планшет

  1. Если у вас была beta 0.10.0, сначала откройте её: «Настройки → Выгрузить полную копию». Сохраните JSON вне приложения.
  2. Старую beta, вероятно, придётся удалить: её старый ключ подписи не сохранился.
  3. Установите YARUS-1.0.0-RuStore.apk. Для ручной установки Android может один раз попросить разрешить установку из выбранного файлового менеджера.
  4. После публикации в RuStore устанавливайте магазинную версию оттуда — она подписана тем же постоянным ключом 1.0.0.

3. Связать устройства без дублей

Компьютер, телефон и планшет подключите к одной доверенной Wi‑Fi/LAN сети. ЯРУС на компьютере должен быть запущен.
На компьютере: Настройки → Участники и приглашения. Выберите адрес вида http://192.168.…:8787, права сотрудника и нажмите «Пригласить».
На телефоне: «Считать QR‑приглашение», разрешите камеру только приложению ЯРУС, наведите её на QR и придумайте отдельный логин/пароль сотрудника.
Повторите для планшета. Каждое приглашение одноразовое и действует 24 часа.

Все подключённые устройства работают с одним серверным каталогом. Одинаковый артикул или штрихкод нельзя создать второй раз. У каждого изменения есть уникальный номер: повторная отправка после обрыва связи не проводит движение дважды.

Не создавайте отдельный «личный склад» на каждом устройстве, если хотите синхронизацию. Личный и общий склады специально не сливаются автоматически: программа не угадывает, какие похожие карточки считать одним товаром.

4. Ежедневная работа

  • Товары: создайте карточку, артикул, единицу, минимум, цену и штрихкод.
  • Места: добавьте склад, комнату, стеллаж или полку.
  • Движение: приход, расход, перемещение и пересчёт всегда сохраняются в истории.
  • Сканирование: используйте камеру, изображение с кодом или внешний сканер‑клавиатуру. Само считывание ничего не списывает — движение нужно подтвердить.
  • Этикетки: в карточке товара или места нажмите «QR‑этикетка», затем сохраните PDF/SVG.
  • Остатки: на странице товаров или в настройках нажмите «PDF‑отчёт». Есть сводный отчёт и подробный по местам.
  • Виджеты: «Настройки → Внешний вид → Виджеты обзора».
  • Виджет Android: удерживайте пустое место на главном экране телефона → «Виджеты» → «ЯРУС». Он показывает последние данные после открытия приложения, без скрытого фонового сервиса.

5. Если пропала сеть

Подтверждённые остатки остаются видимыми в локальной копии. Новая операция сохраняется как черновик и не меняет подтверждённый остаток, пока сервер её не примет. После восстановления связи откройте статус синхронизации. Если другой сотрудник уже изменил остаток, конфликт останется видимым — его нужно проверить, а не скрывать повторной отправкой.

6. Резервные копии и перенос

  1. Раз в день или после большой партии изменений: «Настройки → Выгрузить полную копию».
  2. Храните JSON на другом диске/носителе. CSV — только таблица, без полной истории.
  3. Для общего склада владелец может нажать «Создать копию на сервере». Сервер хранит до 30 последних проверенных копий в data\backups.
  4. Перед переносом Windows закройте ЯРУС, затем скопируйте всю папку программы вместе с data.

7. Если что-то не открывается

  • Windows: убедитесь, что рядом с EXE есть WebView2Loader.dll, а Microsoft Edge WebView2 Runtime установлен. В Windows 10/11 он обычно уже есть.
  • Телефон не видит компьютер: оба устройства должны быть в одной сети; отключите гостевую изоляцию Wi‑Fi; ЯРУС должен быть открыт; брандмауэр — разрешён для частной сети.
  • Порт занят: закройте второе окно ЯРУС и YARUS-server.exe. Один каталог данных может обслуживать только один процесс.
  • APK не обновляет beta: сделайте JSON‑копию, удалите beta и установите 1.0.0.
