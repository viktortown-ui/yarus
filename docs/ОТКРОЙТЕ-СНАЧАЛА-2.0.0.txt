ЯРУС 2.0.0 — КАНДИДАТ ДЛЯ ПРОВЕРКИ
3 ноября 2026 года

WINDOWS
1. Полностью закройте прежний ЯРУС.
2. Откройте «ЗАПУСТИТЬ ЯРУС 2.0.0.exe» рядом с этим файлом.
3. Запускалка может безопасно скопировать соседнюю стабильную базу 1.3.2
   (или 1.3.1–1.1.1) и сохранённый вход. Старая папка остаётся на месте.
4. Сверьте название склада, каталог, остатки и последние движения.
5. Для отдельного чистого испытания откройте
   01-Windows\YARUS-2.0.0-Windows-x64\YARUS.exe и выберите учебный склад.
   Не запускайте программу прямо из ZIP.

ANDROID
APK: «УСТАНОВИТЬ НА ТЕЛЕФОН ЯРУС 2.0.0.apk» или файл в 02-Android.
Пакет и постоянный ключ подписи сохранены. Сначала создайте внешнюю копию.
Не удаляйте прежнее приложение для обычного обновления стабильной версии.
Реальное обновление на вашем телефоне и камера требуют проверки на устройстве.

БРАУЗЕР
В 07-Web находится автономный YARUS.html. Открывайте его в одном профиле браузера
по постоянному пути: данные хранятся в профиле, а не внутри HTML. Перед очисткой
браузера или сменой пути обязательно сохраняйте внешнюю копию.

С ЧЕГО НАЧАТЬ
Откройте учебный склад. Посмотрите обзор, каталог, карточку товара и настройки.
Оставьте включёнными только нужные дополнительные возможности.
Личный склад работает на одном устройстве. Для общей базы выберите одно
главное устройство и подключите остальные по QR-приглашению в одной сети.

ДАННЫЕ
Делайте полную внешнюю JSON-копию. Для личного Android-склада доступен файл
.yarus.json, который сохраняется после удаления приложения.
Главный общий склад переносится защищённым файлом .yarus и отдельным кодом.
После начала работы с копией в 2.0.0 не изменяйте одновременно старую 1.3.2.
Новый журнал 2.0.0 нельзя открывать сервером 1.x после первых новых записей.
Для возврата сохраните старую папку и внешнюю копию до обновления; новые движения
из 2.0.0 не попадут в старую копию автоматически.

СТАТУС
Этот кандидат не загружен на модерацию и не опубликован автоматически.
Стабильные файлы 1.3.2 и их публичные ссылки не заменялись.
Подробности: 04-Документы\MODERNIZATION-2.0.0.md и ИНСТРУКЦИЯ-2.0.0.html.
Результаты проверок: 04-Документы\release-2.0.0-tests.txt.
