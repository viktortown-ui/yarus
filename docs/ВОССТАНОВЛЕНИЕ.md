# Данные, копии и восстановление ЯРУС 1.2.0

## Самое важное

1. У общего склада должно быть одно активное главное устройство.
2. Внешнюю копию храните не на том же устройстве, где рабочая база.
3. Для смены главного используйте `.yarus`-перенос, а не копирование отдельных
   внутренних файлов.
4. Файл переноса и код храните раздельно. Разработчик не знает код и не сможет
   восстановить его.

## Полная JSON-копия

«Настройки → Выгрузить полную копию» создаёт читаемый JSON со всеми товарами,
местами, остатками и полной историей. Пароли, активные сессии и приглашения туда не
входят. Файл подходит для личного восстановления и независимого архивирования,
но не назначает новое главное устройство команды.

JSON содержит коммерческие сведения. Передавайте его только доверенным людям.

## Универсальный файл личного склада `.yarus.json`

Это переносимый файл товаров, мест, остатков и истории без паролей, сессий и
приглашений. Формат версии 1 открывается текущими стабильными версиями ЯРУС.

На Android откройте «Настройки → Сохранность данных → Создать и подключить файл»
и выберите пользовательскую папку, например «Документы». ЯРУС продолжает работать
с быстрой внутренней базой и после каждого изменения обновляет внешний файл. Сам
файл находится вне приватной папки приложения и не удаляется вместе с приложением.

После переустановки:

1. установите ЯРУС;
2. на первом экране нажмите «Открыть файл личного склада»;
3. выберите прежний `.yarus.json`;
4. проверьте название, товары и последние движения;
5. файл снова будет подключён и начнёт обновляться автоматически.

На Windows тот же файл сохраняется и открывается вручную. Это не синхронизация
команды и не способ объединить две независимо изменённые базы. Файл читаемый и не
зашифрован: любой имеющий доступ увидит сведения склада.

## Передача главного склада

1. На старом главном устройстве войдите владельцем.
2. Откройте «Настройки → Передать главный склад».
3. Укажите понятное имя нового устройства и подтвердите предупреждение.
4. Сохраните `.yarus` и отдельно запишите показанный код из 20 символов.
5. Пока новое устройство не подтверждено, старое показывает «Перенос подготовлен».
   Изменения временно остановлены, но можно нажать «Отменить перенос и продолжить
   работу здесь». Старое устройство ещё не стало `retired`.
6. На новом пустом ЯРУС выберите «Перенести сюда главный склад», откройте файл и
   введите код защиты. Новое устройство покажет короткий код подтверждения.
7. Введите короткий код на старом устройстве. Только теперь старое станет копией
   для чтения и покажет код активации.
8. Введите код активации на новом устройстве. После этого оно начнёт принимать
   движения.
9. Создайте новые приглашения и проверьте товары, остатки, историю и тестовое
   движение. Только после проверки архивируйте старую папку/устройство.

Если файл не сохранился, был потерян или новое устройство не открыло его, отмените
перенос на старом устройстве. После подтверждения нового устройства отмена уже
недоступна, но код активации сохраняется на старом и показывается повторно.

## Windows: что лежит в `data`

- `yarus.journal` — зашифрованный журнал;
- `yarus.key` — ключ журнала, защищённый DPAPI;
- `backups` — защищённые внутренние копии;
- `webview` — локальный профиль интерфейса;
- `server.lock` — защита от второго сервера.

`yarus.journal` без соответствующего `yarus.key` не расшифруется. Из-за DPAPI эта
пара рассчитана на того же пользователя Windows. Для нового компьютера используйте
встроенный `.yarus`-перенос. Если всё же архивируете папку вручную, копируйте всю
закрытую папку ЯРУС целиком.

## Android

Главная общая база зашифрована ключом Android Keystore и находится в приватном
хранилище. Очистка данных или удаление приложения уничтожает базу и ключ.
Подключённый `.yarus.json` защищает только личный склад; для общего главного склада
нужен зашифрованный `.yarus`-перенос или свежая полная внешняя копия.

## После сбоя

- Не переустанавливайте приложение и не очищайте данные.
- Не создавайте новый склад с тем же названием «поверх» старого.
- Закройте ЯРУС, сделайте копию всей папки Windows либо оставьте Android как есть.
- Запишите точный текст ошибки и обратитесь: `fixerkrk@yandex.ru` или `@bertosh1`.
- Отправляйте файл базы только если сами решили это сделать и понимаете, какие
  сведения он содержит.

## Рекомендуемый график

- после важных массовых операций — внешняя JSON-копия;
- минимум раз в неделю — копия на другой носитель;
- перед обновлением, переустановкой или переносом — обязательная свежая копия;
- раз в месяц — пробная проверка, что файл открывается в отдельной тестовой копии.
