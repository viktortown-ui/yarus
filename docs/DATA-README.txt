ЭТУ ПАПКУ НЕ УДАЛЯТЬ И НЕ РАЗДЕЛЯТЬ

ЯРУС 1.1.2 хранит здесь зашифрованный журнал общего склада, защищённый ключ,
внутренние копии и профиль интерфейса Windows.

yarus.journal и yarus.key являются парой. Ключ защищён Windows DPAPI для текущего
пользователя Windows. Не отправляйте эти файлы посторонним и не переносите один
без другого.

Перед копированием всей папки закройте ЯРУС. Для переноса главного склада на другое
устройство безопаснее открыть в приложении:
Настройки -> Передать главный склад.

Для обычного архива:
Настройки -> Выгрузить полную копию.
