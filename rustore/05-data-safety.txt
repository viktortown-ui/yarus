ПОДСКАЗКА ДЛЯ АНКЕТЫ ОБРАБОТКИ ДАННЫХ RUSTORE — ЯРУС 1.1.2

Это не автоматический ответ за владельца. Перед отправкой сверить формулировки с
актуальной анкетой RuStore и результатом автоматического анализа AAB/APK.

1. ДАННЫЕ СКЛАДА
Товары, места, остатки, движения, имена участников, логины и хеши паролей
обрабатываются локально либо на главном устройстве, которое выбрал пользователь.
Разработчик не получает их. Review SDK не получает содержимое склада.

2. RUSTORE IN-APP REVIEW SDK
В сборке есть официальный `ru.rustore.sdk:review:10.5.1` и его служебные зависимости.
При подготовке/показе формы SDK связывается с RuStore и может обрабатывать
технические/служебные сведения об устройстве, приложении, учётной записи RuStore и
факте запроса. В анкете необходимо декларировать данные, которые покажет консоль
после анализа SDK; нельзя отвечать «никакие данные третьим лицам» без этой оговорки.
Финальный APK также содержит добавленные SDK разрешения ACCESS_NETWORK_STATE и
RECEIVE_BOOT_COMPLETED и внутреннее signature-разрешение AndroidX. Они не дают
SDK доступ к товарам, остаткам или файлам ЯРУС.

3. КАМЕРА
Используется для QR/штрихкодов после явного действия пользователя. Кадры локально
анализируются, не сохраняются ЯРУС и не отправляются разработчику.

4. СЕТЬ
Используется для выбранного пользователем главного устройства склада и RuStore
Review SDK. В доверенной LAN допускается HTTP к частному адресу. Для интернета
инструкция требует HTTPS/VPN. Поэтому не отмечать «передача всегда шифруется», если
вопрос RuStore относится ко всему сетевому обмену приложения.

5. УДАЛЕНИЕ
Внутренние личные данные удаляются очисткой данных/удалением приложения. Созданный
пользователем внешний `.yarus.json` остаётся в выбранной папке до его ручного
удаления. На Windows владелец закрывает ЯРУС и удаляет папку `data`. Перед этим
предусмотрен внешний экспорт.
Участника общего склада отключает владелец, но удалённо стереть сохранённую на чужом
устройстве копию невозможно.

6. ЗАЩИТА
Главная база Windows/Android и пакет передачи главного склада шифруются. Обычная
JSON-копия и универсальный файл личного склада не зашифрованы. Универсальный файл
создаётся по явной команде, после подключения автоматически обновляется локально.
