Подсказка для анкеты обработки данных RuStore

1. Передаёт ли приложение пользовательские данные разработчику или третьим лицам?
Нет. Внешних API, рекламы, аналитики и облачного аккаунта разработчика нет.

2. Собирает ли приложение товары, остатки, историю, логины или пароли?
Приложение обрабатывает эти данные только локально либо на компьютере‑сервере, который выбрал сам пользователь. Разработчик к ним доступа не имеет.

3. Камера
Используется для QR/штрихкодов после явного действия пользователя. Кадры не сохраняются и не отправляются.

4. Сеть
Используется только для адреса сервера склада, введённого/полученного по QR самим пользователем.

5. Удаление данных
Локальные данные удаляются очисткой данных или удалением приложения. До этого пользователю предлагается сохранить JSON‑копию. Участника общего склада отключает владелец сервера.

6. Шифрование при передаче
В локальной доверенной сети пользователь может выбрать HTTP к частному IP. Для передачи через интернет документация требует HTTPS; прямое открытие HTTP‑порта запрещено инструкцией. Не отмечайте «всегда шифруется», если RuStore формулирует вопрос именно так.

Важно: это практическая подсказка по фактическому поведению версии 1.0.0, а не автоматическое заполнение кабинета. Сверьте формулировки с текущей анкетой RuStore.
