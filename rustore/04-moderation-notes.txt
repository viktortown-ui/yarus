Приложение полностью работоспособно без регистрации и сервера разработчика.

БЫСТРАЯ ПРОВЕРКА
На первом экране нажмите «Сначала посмотреть на примере». Откроется локальный
учебный склад. Можно проверить каталог, места, историю, QR-этикетки, CSV/PDF,
подсказки и темы.

ВНЕШНИЙ ФАЙЛ ЛИЧНОГО СКЛАДА
В личном складе откройте «Настройки → Копии и перенос → Создать и подключить
файл». Используется системный выбор Android (Storage Access Framework), отдельное
разрешение на все файлы не запрашивается. Подключённый `.yarus.json` обновляется
после локальных изменений, остаётся после удаления приложения и открывается через
кнопку первого экрана. Файл содержит складские данные без паролей и не шифруется.

ГЛАВНОЕ ANDROID-УСТРОЙСТВО
На первом экране доступно «Сделать это устройство главным». После создания Android
запускает локальный сервер в диапазоне портов 8787-8797 только пока Activity открыта.
Для второго устройства нужна одна LAN/Wi-Fi сеть. Этот режим не нужен для проверки
личного склада и не пытается работать скрытым фоновым сервисом.

БЕЗОПАСНЫЙ ПЕРЕНОС ГЛАВНОГО
После подготовки файла старое главное устройство переходит в ожидающее состояние,
но не становится окончательно retired. Перенос можно отменить. Статус только для
чтения включается после ввода кода подтверждения, показанного новым устройством;
затем новое устройство активируется отдельным кодом со старого.

РАЗРЕШЕНИЯ
CAMERA запрашивается только после нажатия кнопки сканирования. Без камеры код можно
ввести вручную или выбрать изображение. INTERNET нужен для выбранной пользователем
локальной синхронизации и официальной формы оценки RuStore. Зависимость RuStore
Review SDK сама добавляет ACCESS_NETWORK_STATE и RECEIVE_BOOT_COMPLETED для своего
служебного модуля metrics; эти разрешения не показывают пользователю runtime-диалог
и не дают доступ к содержимому склада. Также AndroidX создаёт внутреннее signature-
разрешение DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION. Интерфейс ЯРУС загружается из
встроенных ресурсов, сайт разработчика не требуется.

ОЦЕНКИ RUSTORE
Подключён официальный `ru.rustore.sdk:review:10.5.1`. Запрос возможен после минимум
7 подтверждённых складских движений в 3 разные даты и не чаще внутреннего интервала
120 дней. Нет отдельной кнопки «Оценить» и предварительного вопроса. Ошибки SDK
пользователю не показываются и работе склада не мешают.

ОБНОВЛЕНИЯ
В Android-интерфейсе раздел «Обновления и загрузка» открывает только официальную
карточку пакета `ru.viktortown.yarus` в RuStore. Ссылки на GitHub и зеркало
Яндекс Диска показываются только в Windows-версии общего интерфейса и в Android
не отображаются.

ДАННЫЕ
Содержимое склада не передаётся разработчику или RuStore Review SDK. Главная база
зашифрована локально. В частной сети пароль, токен и складские HTTP-запросы
дополнительно шифруются AES-256-GCM с ключом из QR-приглашения. Незащищённые
удалённые API-запросы отклоняются. Интернет-доступ требует отдельного HTTPS/VPN.
